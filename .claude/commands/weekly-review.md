1. Run `npm run assets -- week --json`, `npm run assets -- attention --json` and `npm run assets -- works --fy=<this year> --json`.
2. Write the review to `drafts/weekly-review-YYYY-MM-DD.md`: five numbers at the top, then defects past their time, inspections overdue, critical assets below satisfactory, works not started or over budget.
3. Keep it to one page. Every figure must come from the three commands.
4. Show the operator the path and the first five lines. Nothing is sent.
