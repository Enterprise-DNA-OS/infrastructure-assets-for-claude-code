description: The year-end asset pack for the finance team and the auditor.
---

1. Run `npm run assets -- depreciation --json`, `revaluations --json`, `ratios --json`, `backlog --json` and `compliance --json`.
2. Render `npm run docs -- infrastructure-report` and, for any class revalued this year or due, `npm run docs -- revaluation-schedule`.
3. Write `drafts/year-end-<year>.md`: depreciation by class, valuations done and due, the ratios with actual and budget marked, the backlog, and any data gaps the auditor will ask about.
4. Every figure from the commands. Nothing is sent.
